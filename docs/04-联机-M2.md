# 04 · 联机（M2 双人局域网）

> 这一版是**联机玩法的最小可玩形态**：两台机器各跑一块同关卡的棋盘，
> 一块草坪上漏掉的怪**传到队友那块草坪上**——合作 PVE 的核心机制。
> 代码在 `Lawn/Online/`，协议细节以 `NetProtocol.h` 的注释为准，本文件是导航。

## 一、玩法规则（已定，别再改）

| 规则 | 说明 |
|---|---|
| 席位 | 主机 = 1 号位，客户端 = 2 号位。`MAX_PLAYERS = 6`（2026-10-03 六席位批，03 §5.24）；名册 UI 按上限把位子画满（六行） |
| 漏怪是链 | 1 → 2 → 3 → 4。**末席漏怪 = 全队败**（没有下一家可传）。链和"换位"的环不是一回事 |
| 换位是环 | 换位 = 和后一位换，末位的后一位是首位；对面同意才生效（`SWAP_REQUEST`/`SWAP_REPLY`） |
| 末位推车 | 漏怪链**末位**（多人局）每行一台、**整局一次性**——用掉的行记进 RunState（检查点 v5）、跨关不补；**非末位**照旧无除草机（漏怪要传给队友，房前不留兜底）。判定 `NetSession::IsLastRelaySeat()`（链上无下一家且上座 ≥2，单人房不算）；末位不认屋顶清洁车的商店购买位（车本身照旧按场景定型）。见 `03-过程与问题.md` §5.19 |
| 波表 | 主机广播 `level + levelSeed`，两边同一份出怪基准、各按自己的节奏出波；具体出怪量再按各席位顺位缩放（见下行） |
| 出怪乘数（顺位） | 各席位自然刷怪按**上座顺位**直接倍乘（2026-10-03 用户定案，幂次口径取代 4:3:2:1 线性口径；2026-10-04 批七把末位 ×1→×2，见 §5.37）：**末两席同为原量 ×2**、再往前每位**翻倍**——二人 2:2 / 三人 4:2:2 / 四人 8:4:2:2 / 五六人续 16、32（**封顶 ×32**）；每波数量上限同倍放大（六人局 1 号位：闯关 20→640、非闯关 50→1600）。顺位只数**上座席位**（跳过空位，与漏怪链 `NextOccupiedSeat` 同口径）；各客户端只为自己的棋盘缩放、不涉协议。落点 `Board::PickZombieWaves`（旗帜波 ×2.5 之前），见 `03-过程与问题.md` §5.13 / §5.24 / §5.37。2026-10-06 起同一顺位（`LawnApp::OnlineSeatMultiplier`）还决定**开局阳光**：×2→0、×4→+100、×8→+200、×16→+300、×32→+500（从后往前 = 0/0/100/200/300/500；单机/单人 0；**不**叠出怪难度旋钮；基础 50 打底——任何席位开局不低于 50，47f16d5 显式保底）——原「储备」词条同批删除，落点 `Board::InitLevel`，见 §5.45 |
| 判胜 | **所有上座席位**都报"草坪清完"→ 两边一起回主菜单（不发奖杯、不显示结算）。**本席位清完 ≠ 冻结**：清完的草坪保持完全正常运转（阳光照落、植物照产、僵尸掉头/掉币照走）等着，直到全队完成才一起判胜（2026-10-03 用户定案，见 `03-过程与问题.md` §5.26） |
| 全队败 | 末席漏怪 = 全队败：**两边都演"吃脑子"**（客户端不再被直接拽回菜单）。之后**只有主机**能点 Try Again——点了整队重来同一关（同关卡号、同波表种子）；主机选 Main Menu（或客户端点它）两边一起回主菜单。客户端那个框里没有 Try Again，换成一句 `The host decides whether to try again.` |
| 不写档 | 联机局不推进 `mLevel`、不写续玩档（成长留 M4） |
| 闯关（R5） | **第一槽大墓碑**（烤字 ADVENTURE）= 组队闯关入口：队伍连着时由主机起一局闯关，队友被开局命令一路拉进同一关；进度对不上（没检查点 / 检查点落后）由**补发追赶**补齐——欠下的三选一按本机这一局的种子一屏一屏补，屏数、关卡序列与主机一致，具体选什么**各选各的**（卡池两边可以不同，这是设计）。**第三槽 PUZZLE 石板**才是"一起打单关"与原版战役 |
| 闯关规则（R6） | 闯关专属、原版战役一字不动：**蘑菇种下即醒**（白天不睡）、**蘑菇售价 +25**、**咖啡豆改产 100/125/150 阳光**（4+层：基座 4 枚 = 100，每层 +1 枚 = 125/150——2026-10-03 三版终值；种植冷却加长到 12 秒，见 `07-强度与难度调整日志.md`）；**紫卡（升级植物）直接种**，售价 = 原价 + 基础植物价——机枪射手 450 / 双胞向日葵 200 / 忧郁蘑菇 225 / 冰西瓜 500 / 金磁力菇 150 / 地刺王 225 / 香蒲 250 / 玉米加农炮 600（唯一价口 `Plant::GetCost`）。水生四样（睡莲/缠绕海草/水兵菇/香蒲）在闯关里可种草坪、卡的"需要泳池/需要底座"门槛一并放行（2026-10-03 追加定案，见 `03-过程与问题.md` §5.12）；玉米加农炮仍要合法 2×2 |
| 换关时序（R6） | **先全场进草坪、再各自三选一**：命令到达 → 客户端**立刻回 `START_ACK`**（含义 = "命令收到、这就进场"）→ 主机收齐后广播 `RUN_GO` → 各席位在自己的**新草坪**上做三选一（含补发追赶）→ 选完重填卡槽、放开选卡与开场。选项屏不再盖在菜单 / 上一关残局上。时序按最多六席位写（ACK 记账扩席位的账见 §六）。**无尽局（MOD_BUILD 37 追补）例外**：草坪不清，过关留下的老草坪就是下一关的地，三选一摆在老草坪上（见 `03-过程与问题.md` §5.63 同日追补） |
| 选卡等队友 | 选完卡不再一个人先开打：本机报"我选好了"，**所有上座席位都报过才放行**——两边从同一刻起打（各按各的会越差越远）。报的是**两态状态**（1 = 选好 / 0 = 还在选，每轮草坪建好时各报一次当下值，选好了再报一次 1），只覆盖不清位——新一轮的 0 会把上一轮的 1 盖掉，不会有残留提前放行。**门口两处、按卡池分**：卡池>8 挂在 `SeedChooserScreen::CloseSeedChooser` 第一行（Let's Rock 那一刻）；**卡池 ≤8 的关卡全场不开选卡界面**（`ChooseSeedsOnCurrentLevel` 看本机卡池，两边可以不同），门挂在 `UpdateRunPick` 的 picks-done 段（三选一屏全做完就是它的"Let's Rock"：`ShowSeedChooserScreen` 报过 1 之后拦下，草坪冻着等）。放行统一由 `UpdateOnlineSeeds` 收口。等待期间草坪上挂"等待队友选卡"看板框 |
| 闯关难度（M4-a） | 一局 25 关 = 5 场景 × 5 关（关号表见 `03-过程与问题.md` §5.7）；难度按场景 ×1.33（2026-10-05 由 ×1.5 回调：{1000,1500,2250,3375,5062}→{1000,1330,1768,2352,3129}，僵尸血量与出怪点数同乘，整数千分比，两端逐位一致，见 §5.42；历次口径 §5.36）；出怪 = 每波 ≤20 只 + 富余点数只抽强僵尸（价值 ≥4）+ 巨人系价值 4 / 每波合计 ≤2 / 红眼权重与普通巨人同级；种类按名单逐关加码（场景 5 屋顶剔除潜水/海豚/冰车/雪橇）；末波"全种类露面"在闯关关掉。检查点升 v2（v1 档按"没有检查点"处理） |
| 闯关时长档（M4-b；批十重排） | 新局先选时长：**完整版 25 关 / 普通版 10 关（每场景第 1/5 关，=原快速表）/ 快速版 5 关（每场景第 5 关）**——普通/快速 = 从 25 关表抽行（批十 2026-10-05 玩家反馈重排，见 `03-过程与问题.md` §5.43）；奖励口径 = 每关后植物奖 2/6/10 株、增益逐关 3→7 封顶（批十；开局选卡不倍乘，快速版开局 6 株 + 4 增益）；选模式页只有**主机**过（选模式页 UI 见 `RunModeDialog`），队友由 `START_LEVEL` 的 u8 `runMode` 字节带动对齐（`AlignRunToHost`：档位不同 = 删档按主机的档重摆）；检查点 v3 起、批十升 v7（旧非完整档作废、完整档照续），见 `03-过程与问题.md` §5.8/§5.43 |
| 出怪难度档（MOD_BUILD 27） | 房主开局前在选模式页选**全队出怪倍率**：轻松 ×0.5 / 标准 ×1 / 高压 ×2.0（2026-10-04 由 ×1.5 上调，见 `03-过程与问题.md` §5.36）——直接乘在顺位乘数上（乘后向下取整、**保底 1 倍**；每波数量上限随同一乘数放大），落点 `Board::PickZombieWaves`；**难度行只在联机主机显示**（单机档位恒标准）；档位随 `START_LEVEL` 的 u8 `runDiff` 走、进检查点（v4），见 `03-过程与问题.md` §5.18 |
| 末位推车（检查点 v5） | 末位每行一台推车、整局一次性；记账 `RunState::mMowerUsedRows`（bit = 行号）追加在检查点载荷末尾（v4 及更老的档按"一辆没用"续）。**纯本地机制、协议零改动、MOD_BUILD 不动**，见 `03-过程与问题.md` §5.19 |
| 队友场地查看（观战，MOD_BUILD 31） | 按住 **V** 整窗切到队友草坪——全屏只读快照（被看方 ~15Hz 打包，自己模拟照跑不暂停）；按住期间 **1-6** 直选席位、松开 V / **Esc** 退回；对方超时/离开有提示横幅。**中继/云服务器零改动**（分片 ≤250B 卡进单帧限额），见 `03-过程与问题.md` §5.40 |
| 合成僵尸三件套（桶钢门/路障报纸/桶报纸，MOD_BUILD 32） | 闯关自场景 1 第 4 小关起投放的三个合成僵尸：铁桶+铁门 / 路障+报纸 / 铁桶+报纸（双护具）。**漏怪传递帧 `MSG_ESCAPED_ZOMBIE` 的 mZombieType 会带出枚举值 34/35/36**——旧构建解到表外类型会读穿僵尸定义表，两端同版本，见 `03-过程与问题.md` §5.39、§5.41 |
| 无尽（MOD_BUILD 37） | 挑战页生存子页的 **5 张 Endless 卡**不再是原版无尽，改为**锁定环境**的闯关无尽局：每张卡钉死一个场景（昼/夜/泳池/雾夜/屋顶），关卡在该场景 5 个原型内无限循环（关序号 % 5、背景不变）；难度 = 场景基准千分比 + 对数阶增量（初值 600·ln(1+n)，前快后缓，见 `07`）；**无通关**（IsComplete 恒假，到不了奖杯屏），全队败 Try Again 照旧（重打当前关），主动退出留检查点——再点同一张卡先问「继续无尽？」（严格探读）。开局走**选模式页无尽变体**：撤三张时长卡、原位锁环境名行，出怪难度行与「高级选项…」**对单机也摆**（单机无尽同样吃这些档，Board 的顺位乘数去掉 >1 门），底行为「高级选项…/开始/取消」。单机点卡也走这一套（原版单机无尽退役）；大墓碑的「继续闯关？」**不认**无尽档。检查点 v12 |
| 关底巨型 boss + 发阳光（MOD_BUILD 38） | **巨型 boss**：高级选项第五行「巨型 Boss（闯关关底）」开着时，闯关最后一关开始时在**第一席**棋盘刷一只巨型红眼巨人（体尺 ×2；血量 = 原血量 × 顺位乘数和 × 关卡基数 × 2；全控制免疫——减速/冰冻/黄油/魅惑/大蒜换道全免；砸击**破耐砸**——地刺王/忧郁菇/坚果/大蒜的耐砸特例一律跳过、一击压扁整格）；无尽档恒不刷；漏怪照普通传递接力（末席漏它照旧全队败）。**发阳光**：联机闯关局按一下 **G** 进选择态（横幅提示），**1-6 直选队友席位**定向发一档 100（到账 90、税 10），5 秒冷却（发送方各自计）、选择态 5 秒无操作自动退出（G/ESC 也可退）；单机/单人房按 G 提示「没有可发阳光的队友」，钱不够/冷却各有提示；收款方场上**天降三枚面额阳光**（50+25+15 视觉示意，落地自动收进、不重复入账）+ 系统横幅（黑底白字，银行正下方横幅带）。可调值集中两处（`Board.cpp` 顶部 kSunGift\* 与 SpawnRunBoss 旁 kRunBoss\*），见 `03-过程与问题.md` §5.69 |
| 开局流程 | **房主开始 → 队友确认 → 一起进**：主机点开始后菜单上挂"等待其他玩家"看板框，队友弹"是否加入"询问框，点了"加入"两边才进场；点"暂不"主机收到"队友暂不加入"。非闯关局两边各有约 6 秒等待上限（到点两边一起作废，队友不会被落单）；闯关局的等待不设时限、只认掉线（队友可能在补发追赶） |
| 暂停 | 共识模型：任一方能暂停、也能继续；只同步 ESC 那条路（`DIALOG_NEWOPTIONS`）；联机环境（含建房等待，`IsActive()`）切出去/最小化不自动暂停 |
| 退关 | 一方回主菜单，对面跟着回；会话留着，主机直接点 PUZZLE 石板就能开下一局 |
| 掉线 | 心跳 1 秒一次，**5 秒**收不到判死；局中掉线 → 提示死因 + 回主菜单 |

## 二、怎么联机（操作）

0. 启动后在主菜单会先弹一次**玩法公告**（每次启动都有；多页——框下方「上一页 / 下一页」翻页、
   环绕，「知道了」关掉；文案见 `LawnApp::UpdateStartupAnnounce`，§5.46）。
1. **两台机器最好 pull 同一提交**（见 §四）。各自 `git pull` + 重新构建 + 覆盖 exe；
   构建代次不同也连得上（只挂个提醒），但"两边行为一致"只在同版本下成立。
2. 主机：主菜单点**主位那块大墓碑**（烤字是 ADVENTURE——它现在是**组队/闯关入口**，
   牌子上的字是美术烤死的，别当 bug 修）→ **Host**。面板状态行会显示本机 IP 和端口 **27777**；
   首次监听 Windows 会弹防火墙授权，**要点允许**。
3. 队友：点**同一块大墓碑** → 在 Host IP 框里输主机的地址（回车等于点 Join）→ **Join**。
4. 连上后面板自动收起；左上角的小状态条接着显示名册和状态，点它可以再把面板叫出来。
5. 开局前可点 **Swap** 和后一位换位置（要对面按 Accept）。
6. 主机在主菜单点**第三槽的 PUZZLE 石板**（M2 的"一起打单关"走它；没队友时它是单机原版战役）→
   主机这边挂"等待其他玩家"看板框（停在菜单上，不黑屏），队友那边弹"房主开始了游戏 / 是否加入？"
   的中文询问框——**队友点了"加入"两边才一起进**；点"暂不"主机收到"队友暂不加入"的提示。
   非闯关局两边各有约 6 秒等待上限，到点一起作废（不会有"主机不等了、队友还进场"的落单）。
7. **组队闯关（R5；M4-b 起先选时长档）**：队伍连着时，主机点**第一槽的大墓碑** →
   有没打完的检查点先弹"继续闯关？"（继续 = 按原档续打；新开一局 = 进选模式页），
   没有则直接进**选模式页**（完整版 25 关 / 普通版 10 关 / 快速版 5 关三张卡片，取消 =
   不开局）→ 起一局闯关（每关后三选一，植物奖 2/6/10 株、增益逐关 3→7 封顶；快速版
   开局 6 株 + 4 增益，批十口径）。
   队友被自动拉进同一关：同一局种子、同一关序号、同一时长档；队友没检查点或落后
   （档不对也算），会先"补发追赶"
   （把欠下的三选一按本机这一局的种子补完——屏数和关卡序列与主机一致，选什么各选各的；
   R6 起是在**自己的新草坪**上补，见 §一「换关时序（R6）」）。
   队友**从菜单被拉进闯关**（起第一关 / 中途加入）同样先弹"是否加入"的询问框；局中换关不再问
   （那是正常推进），换关等待期间草坪上挂一句 "Waiting for your teammate..."。
   等待期间主菜单留在屏幕上但按钮按不动（防手滑开别的页面）。
8. 关卡里：ESC = 同步暂停；Menu → Main Menu = 两边一起退关。
9. 全队败（末席漏怪）：两边都演"吃脑子"，然后**只有主机**能点 Try Again——点了两边重来同一关
   （闯关局里 = 重打当前这一关，不推进进度）；主机不点、选了 Main Menu，两边一起回菜单
   （会话还在，直接再开一局）。
10. **看队友场地（观战）**：联机局里按住 **V**——整窗切成队友的草坪（顶部挂着"正在观看
   X 的场地 · 第 n/m 波"），自己的草坪照跑不暂停；按住期间按 **1-6** 换人看，松开 V 或
   按 **Esc** 退回自己画面。对方没响应/已离开会给一条提示横幅。

## 六、M3 要动的结构性地方（本次排查留的账）

> **M3 已落地**（中继、席位表、按席位记账）：本章是 M2 当时的留账，已完成项与
> 后续安排以 [`05-联机-M3.md`](05-联机-M3.md) 为准。

- `mPeerSeat`/`mPeerName` 是单数：会话模型本身是"一个对端"。
- 每条消息 `mDstSeat = mPeerSeat`：线格式还表达不了"发给所有席位"（走中继时再定广播语义）。
- `ApplySeatSwap` 是两席位对调；换位协议要改成按请求里带的两个座次置换。

  放行同样借这个单槽（`mHasRunGo`）：扩四时一并换成按席位记账，收齐**所有上座席位**
  的 ACK 才广播放行（现在别写死"就是那两个人"）。选卡等队友（`SEEDS_READY`）同理：
