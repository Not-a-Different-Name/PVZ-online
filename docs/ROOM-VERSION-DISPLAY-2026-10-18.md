# 房间版本显示调整 · 2026-10-18

按用户定案：“版本仅显示房主版本；其他人版本显示在自己位置”，随后要求“字太显眼了”。本轮修改当前Build68工作区的PC与Android源码，保留先前大厅、最近记录和补位改动；不改变联机版本、协议、存档或版本兼容判定。

## 界面结果

- 顶部右侧仅显示实际房主的版本，房主换位后跟随新的房主席位读取；不再把P2当作所有人的“对方”。
- 六个有人席位各自显示该玩家版本，位置在席位状态行右侧；姓名和准备状态保留。空席不显示版本，尚未收到版本时显示“待同步”，不会显示MOD0。
- 所有版本标签统一为14字号参数、RGB(145,160,165)灰色，独立于醒目的状态标题和玩家姓名；不使用黄色或橙色强调版本号。
- 房间版本不一致时仍保留整体提醒，详情改为提示查看各席位，不再出现“本机63 / 对方63却版本不同”的错误对照。
