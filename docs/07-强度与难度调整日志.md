## 2026-10-03 六席位批：顺位乘数改 2 的幂（封顶 ×32）+ 席位上限 4→6

用户口径（原话）：「把乘数改回1248 16……，允许4人以上联机」——问询后定案：乘数封顶 ×32、
席位上限 6、旧包宽松过渡（MOD_BUILD 27→28 只提示不拒连）。

- **顺位乘数**：**4:3:2:1（线性，§5.13 口径）→ 2 的幂**——末席 ×1、往前每位**翻倍**：
  二人 2:1、三人 4:2:1、四人 8:4:2:1、五人 16:8:4:2:1、六人 32:16:8:4:2:1，**封顶 ×32**；
  每波数量上限同倍放大（数组 ×8 → ×32：非闯关 50×32 = 1600 顶到数组上限），
  难度档（×0.5/×1.5，§5.18）仍乘在其上。落点 `Board::PickZombieWaves`。
  落地：A **27e3b8e**（乘数）+ B **fbb9b30**（数组 ×32）。
- **席位上限**：**4 → 6**（`NetProto::MAX_PLAYERS`、Go 中继 `maxPlayers`）——合作压力
  随席位数走高是设计意图（同「高压能带来乐趣」口径）。落地：B **fbb9b30** + C **77e2777**。
- 验收要点与顺带修的收包加固（空座位伪造消息）：见 `03-过程与问题.md` §5.24。
