# 强度调整 · 全数值总表

> **用途**：给"数学建模调强度"用的数据源。所有数值 = **当前工作树代码的实际运行值**
> （含本 mod 的全部改动），不是原版 PvZ 的值。标 **[MOD]** 的条目是与原版不同或本 mod 新增。
> 生成日期 2026-10-08；源码基线提交 `945a43a`（= 已推远端 `github/pvz-online`）。
>
> **单位口径**（建模前必读）
> - **时间 = 帧**：100 帧 = 1 秒（PvZ 内部 tick）。源代码里种子卡冷却等字段是**厘秒**
>   （750 = 7.5 秒）；本表正文用秒时已换算，括号注原始帧/厘秒。
> - **距离 = 像素**：草坪 1 格 = 80×80 px。常规草坪 **9 列 × 5 行**（泳池关 6 行，其中
>   中间 2 行是水面）；"行"从 0 数起（0 = 最上）。
> - **血量 = 整数点**。僵尸血量在闯关里还要**乘难度阶梯**（§3.2），本表给的是**基础值**。
> - **阳光 = 整数点**。一枚普通阳光 25、小阳光 15、大阳光 50（Coin.cpp:1303）。
> - **xN / ×N**：乘数链一律"先基础值、再逐级乘"（§0.3 给了完整顺序）。

## 0. 全局口径

### 0.1 这张表覆盖什么

- 植物：48 种常规植物（SeedType 0..47）+ 模仿者（48）+ 仅特殊模式出现的 4 个内部株
  （爆炸坚果 49 / 巨坚果 50 / 幼芽 51 / 左向重复者 52）。

- 全局公式：出怪点数、难度阶梯、顺位乘数、阳光经济、增益（buff）全表。

### 0.2 原版值 vs 本 mod 的差异在哪

### 0.3 乘数链（一次算清一只僵尸/一株植物的实际值）

```
僵尸实际血量 = 基础血量(§2.2) × 难度阶梯千分比(§3.2) ÷ 1000        // Zombie.cpp:926-936
僵尸实际出怪量 = 波次点数(§3.1) × 难度阶梯 ÷ 1000 × 顺位乘数(§3.3)
                                              × 出怪旋钮(§3.2) ÷ 1000

植物实际血量 = 基础血量(§1.2) × (1 + 0.75×扎根层数) × (1 + 1.5×单株血量行层数)   // Plant.cpp:527
子弹伤害     = 基础伤害(§1.3) × (1 + 0.30×火力层数) × (1 + 0.15×精准层数)
一次性伤害   = 基础伤害(§1.3) × (1 + 0.60×爆破层数) × (1 + 0.15×精准层数)
攻击间隔     = 基础间隔(§1.1/§1.3) × 0.8^急袭层数 × 单株节奏行系数(§4.2)
种植冷却     = 基础冷却(§1.1) × 0.8^速种层数 × 单株冷却行系数(§4.2)
```

精准（id 7）的挂点在 `Zombie::TakeDamage` 总入口——**所有**伤害都吃它，包括上面各行。
联机注意：难度乘除全程**整数**（两端逐位一致），其余乘数只影响本机。

## 3. 全局公式

### 3.1 出怪点数与抽取（Board::PickZombieWaves / PickZombieType）

**每波预算**（闯关分支，`Board.cpp:749`）：
```
点数 = 波次号 × 2 ÷ 5 + 3            // 整数除；波次号 0 起
点数 = 点数 × 难度阶梯千分比 ÷ 1000   // §3.2，旗帜波也吃
点数 = 点数 × 顺位乘数               // §3.3（联机）
点数 = 点数 × 出怪旋钮千分比 ÷ 1000   // §3.2（轻松 500/标准 1000/高压 2000）
```
- **旗帜波**（每 10 波末）：先按 `min(点数, 8)` 预放若干普通僵尸 + 1 面旗帜（照常扣点），
  点数再 ×2.5，余下正常抽。
- **末波**（最后一波）：点数照常，没有额外加成（原版"末波全怪露面"在闯关关掉 [MOD]）。
- **花点数**：加权随机抽一只，抽中就从点数里扣它的§2.1 点数值，循环到点数 <1 或数量达上限。
- **数量上限**：每波 `20 × 顺位乘数`（RUN_WAVE_ZOMBIE_CAP=20）；空间不足的零头作废
  ——富余点数靠下面的"强怪优先"花在质量上。
- **强怪优先** [MOD]（`Board.cpp:2835`）：当剩余点数 ≥ **16**（RUN_HEAVY_POINTS）时，
  把点数值 < **4**（RUN_HEAVY_VALUE）的类型权重清零，只从强怪里抽（强怪全抽不起就保持原样）。
- **巨人闸门** [MOD]：巨人/红眼**每波合计至多 2 只**（RUN_GARGANTUAR_CAP）；点数值压到 4。
- 巨人以外的准入闸：剩余点数 ≥ 点数值（买得起就进池），**不看**原版 firstAllowedWave。

### 3.2 难度阶梯与出怪旋钮

- **难度阶梯**（`RunState::GetDifficultyPermille`，`RunState.cpp:466`）：按**场景档** 0..4
  | 场景 | 1 白天 | 2 夜 | 3 泳池 | 4 雾 | 5 屋顶 |
  |---|---|---|---|---|---|
  | 千分比 | 1000 | 1330 | 1768 | 2352 | 3129 |
  即每过一场景 **×1.33**（批九 2026-10-05 定）。同一千分比**同时**乘（a）僵尸血量
  四项（§2.2）与（b）每波点数（§3.1）——血量与数量同涨。整数乘除，联机两端逐位一致。
- **出怪旋钮**（`RunState::DiffPermilleFor`）：轻松 500 / 标准 1000 / 高压 2000。
  乘在**顺位乘数**上（乘后向下取整、保底 1 倍），再乘进点数；只在闯关局生效。房主开局
  定一次，随 START_LEVEL 走。

### 3.3 顺位乘数（联机）

`LawnApp::OnlineSeatMultiplier`（`LawnApp.cpp:2080`）：按"上座席位"排，第 r 位（1 起）
= `2^(n-r)`，末两席保底 ×2，封顶 ×32。六人局 = 32:16:8:4:2:2。同一乘数**也**放大
每波数量上限（20×32=640）与**开局阳光**（§3.5）。单机/单人 = 1（开局阳光 0）。

### 3.5 阳光经济

- **开局阳光**（`Board::InitLevel`）：基础 **50**（闯关所有关；原版其余模式同 50）+
  顺位加成 0/0/100/200/300/500（按 §3.3 乘数档：×4→100、×8→200、×16→300、×32→500，
  末两席 0）；闯关保底 **≥50**（2026-10-06 追补，显式钳制）。
- **天降阳光**（白天/无论何种关卡，除特殊模式）：第一枚 `425..700` 帧（4.25~7 秒，
  `RandRangeInt(425,700)`）；其后每枚间隔 `min(950, 425 + 已落枚数×10) + Rand(275)` 帧
  ——即 4.25~12.25 秒，越落越慢，封顶 9.5+2.75 秒。
- **天降 buff（Skyfall）** [MOD]：夜晚/迷雾关也起倒计时，且上两式**再 ×0.25**
  （`RunSkySunIntervalMul`）——即速率 ×4。
- 一枚普通阳光 = **25** 点。

### 4.3 抽取机制（RunState::RollChoices，RunState.cpp:183）

- **每屏 3 条互不重复**；**第 1 格保底一条全局**（全局全封顶时自然让位）。
- 候选池分母 = 8 条全局中未封顶的 + 48 条单株中"卡池已有该株且未封顶"的。
  当前是**均匀抽取**（等概率）——没有稀有度/权重维度。
- 已封顶的条目**不进候选**（`GetBuffCount(id) >= mMaxStacks` 即过滤）。
- 候选由 `runSeed ⊕ 关序号 ⊕ 抽取次数 ⊕ 本机盐` 推导——联机各人候选不同、选择各选各的。
- 「换一批」= 同一屏重抽一次（每屏限一次），走同一函数、抽取计数器 +1。
