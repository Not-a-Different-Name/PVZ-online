# PvZ Online — 多人合作 PVE

当前版本：**MOD110**，完整电脑与安卓包见[Releases](https://github.com/Not-a-Different-Name/PVZ-online/releases/tag/mod110-full-20261102)。电脑和安卓联机须全队同版。

游戏自动选择官方服务器，分享四位房间码即可加入，支持复制粘贴。也支持最多6人的自建联机，各自守草坪，漏怪向下一位队友传递。无需玩家处理官方服务器。

## 玩法与操作

- 闯关与无尽、个人增益、僵尸强化投票、全队增益和队友互助。
- 无尽有“开始新无尽／继续存档”两个入口，多局各自保留；联机房主选局，全队恢复共同开局档，缺档按补位规则加入。
- 完成前置选择即可参与团队投票，无倒计时；慢选和短暂掉线保留资格。局内“增益→全队增益”查看名称、层数和效果。
- 战斗收起后左侧窄“队友”入口保留人数/求援标记，点开名单后可求阳光、切换接收支援，再点名字送阳光、支援卡或观战。准备时可借植物、直接答复来信。
- 支援卡可送樱桃、寒冰菇、辣椒和南瓜；协作增益包含应急维修、借兵助阵和全队补给。交易沿用实际费用、许可及冷却。
- 观战画面可继续攻击、受伤、死亡和出怪；点击刷新查看新的战况，点击选人切换。电脑支持V/R和数字选人，H/J切换血量；安卓可操作界面按钮。关闭名单优先于退出观战。P2P默认关闭，在选项的帮助设置中可开启。
- 机枪射手新增三星火力全开，大嘴花连锁吞后续追咬加快；小丑和蹦蹦强化已调整。
- 金币可用于重摇锁定候选和外观名牌；协作/无尽成就与收藏不提供永久战斗属性。

## 构建与更新

Windows使用VS2022/MSVC x86、CMake/Ninja Release；Android使用SDK36/min24、NDK28.2.13676358、arm64、CMake3.22.1、Gradle8.12。双端从同一固定输入构建并记录SHA256；工作目录包含未提交改动，不能用旧HEAD代表完整源码。

PC完整解压后运行“启动游戏.bat”，安卓覆盖安装，不要先卸载。更新前正常保存退出并备份存档；不会强制关闭玩家对局。源码与完整玩家资源分开交付，素材不提交源码分支；保留原作及第三方许可证。

- 此前原始冰瓜闪退与前台异常掉线尚未全部归因。排山倒海重叠种植、返回菜单悬空引用、同轮开局恢复和观战互看等各有确切修复，不等于所有同类现象根治。
