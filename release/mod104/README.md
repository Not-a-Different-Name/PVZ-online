# MOD104 sources

MOD104 exposes teammate actions through a permanent name list and fixes endless preparation replay and briefly disconnected voter recovery. It includes the accepted shared spectator resource identities and clipping corrections from MOD103. Authenticated direct pictures, snapshot fallback, team progression and collections remain. SOURCE-MAP.json records the accepted files and keeps the previous remote history.

PC: VS2022 MSVC x86, CMake/Ninja Release. Extract Source-Dependencies.zip beside the checkout to supply third_party. Android: SDK36/min24, NDK28.2.13676358, arm64, CMake3.22.1 and Gradle8.12. Licensed dependencies are retained; signed full player packages are in Releases. No player data, credentials or signing keys are included.
