# MOD113 sources

MOD113 adds two zombie buffs and introduces a 20-stack start snapshot. Combat and spectators share six seats. Mid-game joins and reconnects can watch, then switch roles between stages. The full release carries the tested desktop client and arm64 APK. SOURCE-MAP.json records the accepted files and keeps the previous remote history.

PC: VS2022 MSVC x86, CMake/Ninja Release. Extract Source-Dependencies.zip beside the checkout to supply third_party. Android: SDK36/min24, NDK28.2.13676358, arm64, CMake3.22.1 and Gradle8.12. Licensed dependencies are retained; signed full player packages are in Releases. No player data, credentials or signing keys are included.
