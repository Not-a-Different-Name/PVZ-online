# MOD118 sources

MOD118 updates shared finale health and the night-roof roster, previews plant buffs during selection, and fixes Android camera panning and co-op almanac closing. The START payload remains 56 bytes. The new shared health on public relay rooms requires the matching relay build. SOURCE-MAP.json binds the player sources to the accepted snapshot.

PC: VS2022 MSVC x86, CMake/Ninja Release. Extract Source-Dependencies.zip beside the checkout to supply third_party. Android: SDK36/min24, NDK28.2.13676358, arm64, CMake3.22.1 and Gradle8.12. Licensed dependencies are retained; signed full player packages are in Releases. No player data, credentials or signing keys are included.
