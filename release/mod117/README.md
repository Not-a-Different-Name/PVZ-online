# MOD117 sources

MOD117 adds the optional shared-health Zomboss finale and intermission difficulty changes. Build 117 uses the existing 56-byte START payload. An unresolved difficulty selection is saved as checkpoint v29. Online finales require the companion relay. SOURCE-MAP.json binds this release to the accepted snapshot.

PC: VS2022 MSVC x86, CMake/Ninja Release. Extract Source-Dependencies.zip beside the checkout to supply third_party. Android: SDK36/min24, NDK28.2.13676358, arm64, CMake3.22.1 and Gradle8.12. Licensed dependencies are retained; signed full player packages are in Releases. No player data, credentials or signing keys are included.
